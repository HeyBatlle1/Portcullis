An AI agent can propose a payment. It can't make one.

The agent works an accounts-payable inbox over MCP. Every payment it asks for goes to a deterministic policy kernel with no model in it, which allows or refuses it by rule. Only an allowed payment reaches PayPal. Every decision is written to a hash chain, and this page re-checks that chain in your browser.

A script holding the agent's real token tries six ways to steal or short-pay an approved bill. No model, a few seconds. Six different rules refuse it.
  1. 1
    Agent reads mail and calls propose_payment. It never sees the rules.
  2. 2
    Kernel checks payee, amount, bill, limits and balance. Rust, no network, no prompt.
  3. 3
    PayPal Payouts sends only what was allowed, keyed so a retry can't pay twice.
  4. 4
    Audit chain records every step as SHA-256 linked records, verified below.
